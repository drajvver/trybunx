# Interfejs użytkownika

- Wszystkie teksty widoczne dla użytkownika muszą być po polsku, w tym teksty
  w oknach systemowych wywoływanych przez aplikację.
- Przy każdej zmianie dotyczącej interfejsu należy zachować polski jako
  domyślny język UI oraz sprawdzić nowe i zmienione komunikaty, etykiety,
  podpowiedzi, przyciski i stany błędów.
